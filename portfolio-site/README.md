# Portfolio personnel — Lhoussaine Thoumi

Site vitrine statique (HTML/CSS/JS) présentant le parcours et les projets de
Lhoussaine Thoumi, dont [HalloApp](../README.md).

**Ce dossier n'est pas le produit HalloApp** : c'est un artefact séparé
(page perso), conservé dans ce dépôt par commodité. Si ce site est publié via
GitHub Pages ou un hébergement indépendant, envisager de l'extraire dans son
propre dépôt pour ne pas mélanger deux publics différents (recruteurs
consultant la vitrine vs. développeurs/clients évaluant le code du produit).

## Structure

```
portfolio-site/
├── index.html
├── projects/       # pages dédiées par projet (dont hallo.html)
└── assets/
    ├── css/
    ├── js/
    └── img/
```

## Utilisation locale

Fichier statique — ouvrir `index.html` directement dans un navigateur, ou
servir le dossier avec n'importe quel serveur statique (`npx serve .`).
