# Code de conduite

## Notre engagement

Dans l'intérêt de favoriser un environnement ouvert et accueillant, les
contributeurs et mainteneurs s'engagent à faire de la participation à ce
projet une expérience respectueuse pour tout le monde, sans distinction
d'âge, de genre, de handicap, d'origine ethnique, de niveau d'expérience,
de nationalité ou de religion.

## Nos standards

Exemples de comportements attendus :

- Faire preuve d'empathie et de bienveillance envers les autres
- Respecter les avis, points de vue et expériences différents
- Donner et accepter avec grâce des retours constructifs

Exemples de comportements inacceptables :

- Langage ou contenu à caractère sexuel, insultant ou dénigrant
- Harcèlement public ou privé
- Publication d'informations privées d'autrui sans consentement explicite

## Application

Les cas de comportement abusif peuvent être signalés en contactant l'auteur
via le profil GitHub [@thoumi](https://github.com/thoumi). Toutes les
plaintes seront examinées et traitées de manière appropriée.
