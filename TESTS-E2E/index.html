    🤖 Scripts de Test Automatisés¶

    PowerShell (Windows)¶

    Créer run-tests.ps1:

    # Test Health Checks
Write-Host "🏥 Testing Health Checks..." -ForegroundColor Cyan

$services = @(
    @{Name="Core API"; Url="http://localhost:5001/health"},
    @{Name="Chatbot Service"; Url="http://localhost:5002/health"},
    @{Name="Media Service"; Url="http://localhost:5003/health"},
    @{Name="API Gateway"; Url="http://localhost:5000/health"}
)

foreach ($service in $services) {
    try {
        $response = Invoke-WebRequest -Uri $service.Url -TimeoutSec 5
        if ($response.StatusCode -eq 200) {
            Write-Host "✅ $($service.Name) is healthy" -ForegroundColor Green
        }
    }
    catch {
        Write-Host "❌ $($service.Name) is unhealthy" -ForegroundColor Red
    }
}

# Test Chatbot
Write-Host "`n💬 Testing Chatbot Service..." -ForegroundColor Cyan

$loginBody = @{
    username = "testuser"
    password = "Pa`$`$w0rd"
} | ConvertTo-Json

$loginResponse = Invoke-RestMethod -Uri "http://localhost:5000/api/account/login" `
    -Method Post -Body $loginBody -ContentType "application/json"

$token = $loginResponse.token

$chatBody = @{
    message = "Test message from automation"
} | ConvertTo-Json

$chatResponse = Invoke-RestMethod -Uri "http://localhost:5000/api/chatbot/chat" `
    -Method Post -Body $chatBody -ContentType "application/json" `
    -Headers @{Authorization = "Bearer $token"}

Write-Host "✅ Chatbot response: $($chatResponse.response)" -ForegroundColor Green

Write-Host "`n✅ All tests passed!" -ForegroundColor Green

    Bash (Linux/Mac)¶

    Créer run-tests.sh:

    #!/bin/bash

echo "🏥 Testing Health Checks..."

services=(
    "Core API:http://localhost:5001/health"
    "Chatbot Service:http://localhost:5002/health"
    "Media Service:http://localhost:5003/health"
    "API Gateway:http://localhost:5000/health"
)

for service in "${services[@]}"; do
    IFS=':' read -r name url <<< "$service"
    if curl -f -s "$url" > /dev/null; then
        echo "✅ $name is healthy"
    else
        echo "❌ $name is unhealthy"
    fi
done

echo ""
echo "💬 Testing Chatbot Service..."

# Login
TOKEN=$(curl -s -X POST http://localhost:5000/api/account/login \
    -H "Content-Type: application/json" \
    -d '{"username": "testuser", "password": "Pa$$w0rd"}' \
    | jq -r '.token')

echo "Token: $TOKEN"

# Test chatbot
RESPONSE=$(curl -s -X POST http://localhost:5000/api/chatbot/chat \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{"message": "Test message from automation"}')

echo "✅ Chatbot response: $(echo $RESPONSE | jq -r '.response')"

echo ""
echo "✅ All tests passed!"

    Rendre exécutable: 

    chmod +x run-tests.sh
./run-tests.sh

    📊 Vérification des Métriques¶

    Seq - Logs Centralisés¶

    1. Accéder à http://localhost:8081
    2. Filtrer par niveau:
    3. @Level = 'Information'
    4. @Level = 'Error'
    5. Filtrer par service:
    6. Service = 'CoreAPI'
    7. Service = 'ChatbotService'
    8. Service = 'MediaService'
    9. Rechercher des événements:
    10. @MessageTemplate contains 'photo.uploaded'
    11. @MessageTemplate contains 'Chatbot'

    RabbitMQ - Messages¶

    1. Accéder à http://localhost:15672
    2. Vérifier les Connections (services connectés)
    3. Vérifier les Queues:
    4. Messages ready
    5. Messages unacknowledged
    6. Throughput rate

    🐛 Troubleshooting¶

    Service ne démarre pas¶

    # Vérifier les logs
docker-compose logs SERVICE_NAME

# Redémarrer un service
docker-compose restart SERVICE_NAME

# Reconstruire
docker-compose up -d --build SERVICE_NAME

    RabbitMQ ne reçoit pas les événements¶

    # Vérifier la connexion
docker-compose logs media-service | grep RabbitMQ
docker-compose logs core-api | grep RabbitMQ

# Redémarrer RabbitMQ
docker-compose restart rabbitmq

    Seq ne reçoit pas les logs¶

    # Vérifier la variable SEQ_URL
docker-compose exec core-api env | grep SEQ

# Tester manuellement
curl -X POST http://localhost:5341/api/events/raw \
  -H "Content-Type: application/json" \
  -d '{"@t":"2025-10-10T12:00:00Z","@mt":"Test","@l":"Information"}'
